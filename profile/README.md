# <img src="https://raw.githubusercontent.com/zmina-app/.github/main/profile/zmina-icon.png" width="64" align="absmiddle" alt=""> Zmina

Zmina sits between copy and paste. It reads what's in the clipboard and where you paste, and offers a short list of actions you can apply. Without switching apps.

[![Zmina: The app between copy and paste (60s Demo)](https://img.youtube.com/vi/f2IlhmUrDo0/maxresdefault.jpg)](https://youtu.be/f2IlhmUrDo0)

macOS · Built in Rust with Tauri · 14-day full trial, then a one-time purchase. Not a subscription.

No accounts, no telemetry, no crash reports, nothing you copy leaves your Mac.
